JSON Parser & Query Engine

This project parses JSON data and allows users to query it using dot-path and filter queries.

System Design

Architecture

JSON File
    |
    v
JSON Parser
    |
    v
Indexer
    |
    v
Query Executor
    ^
    |
Query Parser

The JSON Parser reads the input file and creates an in-memory representation of the data. The Indexer builds lookup structures to make repeated queries faster.

The Query Parser converts the user's query into an internal structure. The Query Executor then uses that structure to find and return the requested data.

Modules

JSON Parser

Converts JSON text into an internal data structure. The file is parsed once and reused for multiple queries.

Indexer

Builds lookup structures so the entire JSON document does not need to be searched again for every query.

Query Parser

Parses dot-path, wildcard, array index, and GET...FROM...WHERE queries.

Query Executor

Executes the parsed query against the JSON data and returns the result.

Query Language

Dot-Path Queries

School.students.name

Array index:

School.students[2].name

Wildcard:

School.students[*].name

Filter Queries

GET name FROM School.students

With a condition:

GET name FROM School.students WHERE year > 2

Multiple conditions:

GET name FROM School.students WHERE year > 2 AND grade >= 90

Supported Operators

  • =
  • !=
  • <
  • <=
  • >
  • >=

Current Limitations

  • OR and NOT are not supported.
  • Parentheses in filter conditions are not supported.
  • Users cannot currently choose the ordering of results.

  • Valid and invalid dot paths
  • Wildcards
  • Array indexes
  • Filter queries
  • AND conditions
  • Invalid keywords and syntax
  • Whitespace and malformed operators

Example Tests

Edge Cases

  • Missing keys
  • Empty arrays and objects
  • Null values
  • Out-of-range indexes
  • Negative indexes
  • Deep nesting
  • Invalid syntax
